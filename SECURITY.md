# Security Policy

## Supported Versions

| Version | Minecraft | Supported          |
| ------- | --------- | ------------------ |
| 1.1.x   | 1.20.1    | :white_check_mark: |
| < 1.1.0 | <= 1.20   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in **SekCLib** (such as network packet deserialization or capability synchronization issues), please report it privately via GitHub Security Advisories on [Hamza-Zengin/SekCLib](https://github.com/Hamza-Zengin/SekCLib/security/advisories) rather than opening a public issue.
